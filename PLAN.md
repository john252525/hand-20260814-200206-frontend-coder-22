# План завершения MVP (2–3 недели)

## 1. Интеграция реальных API
- Добавить на бэкенде эндпоинты `GET /api/v1/files` и `GET /api/v1/communications/threads`.
- Убрать моки из `files.ts` и `communications.ts` (или переключить флаг `NEXT_PUBLIC_USE_MOCKS=false`).
- Синхронизировать контракты с командой бэкенда.

## 2. Завершение настроек
- Реализовать полноценные разделы «Шаблоны» и «Интеграции».
- Добавить сохранение шаблонов сообщений и интеграционных ключей.

## 3. Расширение администрирования
- Добавить управление пользователями (создание, блокировка, смена ролей).
- Добавить тестирование вебхуков (test) и просмотр истории доставки.
- Добавить управление источниками (редактирование, синхронизация).

## 4. Улучшение real-time функциональности
- Подписать на WebSocket-события список тендеров, поставщиков, КП, переговоров.
- Инвалидировать кэш при событиях `tender:status_changed`, `cp:received`, `task:completed`.

## 5. Тестирование и CI/CD
- Расширить e2e-тесты: коммуникации, переговоры, экспорт.
- Настроить деплой на staging (Vercel или Docker + k8s).
- Добавить проверку покрытия тестами в CI.

## 6. Подготовка к пилоту
- Наполнить демо-данными.
- Провести нагрузочное тестирование (при необходимости).
- Подготовить документацию пользователя.
